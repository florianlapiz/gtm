# Inovexus — Pipeline Readiness Check

60-second GTM diagnostic for Pre-Seed and Seed B2B SaaS founders in the Inovexus
acceleration cohort. Five levers (ICP, Signal vs Volume, Stack-Phase Fit, Founder
Mode, PMF Reality) → score 0–10 → tier (Foundation / Finding Repeatability /
Ready-to-Scale) → three priority operator plays from the workshop material →
CTA for a 1:1 mentor slot with Florian.

**cohort mentor**, not one-off workshop speaker. Same five levers used in the

emergency-playbook material.
